## Program Overview

The Deep Learning Specialization is a foundational program by deeplearning.ai, taught by Andrew Ng on Coursera. It consists of five courses that build expertise from neural network basics to advanced architectures.

## Courses Completed

- **Neural Networks and Deep Learning** — Forward/backpropagation, activation functions, deep L-layer networks
- **Improving Deep Neural Networks** — Bias/variance, regularization, optimization algorithms, hyperparameter tuning
- **Structuring Machine Learning Projects** — ML strategy, error analysis, transfer learning, multi-task learning
- **Convolutional Neural Networks** — ConvNets, object detection, face recognition, neural style transfer
- **Sequence Models** — RNNs, LSTMs, GRUs, attention models, transformers
