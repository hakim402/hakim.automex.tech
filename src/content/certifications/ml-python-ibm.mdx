## Course Overview

This IBM professional course on edX provides a comprehensive introduction to machine learning using Python, covering both theory and hands-on implementation with scikit-learn.

## Skills Acquired

- **Supervised Learning** — Linear/logistic regression, decision trees, random forests, SVMs, k-NN
- **Unsupervised Learning** — K-means clustering, hierarchical clustering, DBSCAN, PCA
- **Model Evaluation** — Cross-validation, confusion matrices, ROC curves, precision-recall, F1 scores
- **Recommender Systems** — Content-based and collaborative filtering approaches

**Platform**: edX | **Provider**: IBM | **Language**: Python (scikit-learn, pandas, numpy)
