## Certification Details

The AWS Certified Solutions Architect — Associate (SAA-C03) certification validates the ability to design and deploy scalable, highly available, and fault-tolerant systems on AWS.

## Key Topics Covered

- **Compute** — EC2, Lambda, ECS, EKS
- **Storage** — S3, EBS, EFS, Glacier
- **Databases** — RDS, DynamoDB, ElastiCache, Redshift
- **Networking** — VPC, Route 53, CloudFront, API Gateway
- **Security** — IAM, KMS, WAF, Shield, Cognito
