## Abstract

We investigate parameter-efficient fine-tuning (PEFT) strategies for adapting large language models to code generation tasks. Our experiments compare QLoRA, adapter layers, and prefix tuning across CodeLlama, DeepSeek-Coder, and StarCoder2 models. QLoRA achieves 97.3% of full fine-tuning performance while reducing trainable parameters by 99.8%, making LLM-based code generation accessible on consumer hardware.

## Key Findings

| Method | Parameters Trained | HumanEval Pass@1 | MBPP Pass@1 |
|--------|-------------------|------------------|-------------|
| Full Fine-Tuning | 100% | 72.1% | 68.4% |
| QLoRA (rank=64) | 0.2% | **70.3%** | **66.1%** |
| Adapter Layers | 1.1% | 67.8% | 63.9% |
| Prefix Tuning | 0.05% | 63.2% | 58.7% |

## Contributions

- First systematic comparison of PEFT methods for code generation across three open-source LLM families
- Novel evaluation benchmark combining HumanEval, MBPP, and multi-language CodeContests
- Open-source release of PEFT checkpoints and evaluation harness
