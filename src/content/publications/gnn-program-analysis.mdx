## Abstract

We present GNN-SCAN, a graph neural network framework for automated program analysis that operates on code property graphs (CPGs). Our approach combines abstract syntax trees, control flow graphs, and data dependency graphs into a unified graph representation, then applies message-passing neural networks to detect security vulnerabilities. On a benchmark of 12 C/C++ projects containing 1,847 verified vulnerabilities, GNN-SCAN achieves 91.2% recall at 84.7% precision, outperforming both pattern-based static analyzers and sequence-based deep learning baselines.

## Architecture

The system operates in three stages:

- **Graph Construction** — Parse source code into a CPG combining AST, CFG, and DDG edges. Node features encode token type, operation, and position embeddings.
- **GNN Encoder** — A 6-layer GATv2 (Graph Attention Network) processes the CPG with edge-type-specific attention heads and positional encoding.
- **Vulnerability Classifier** — Graph-level readout via mean+max pooling followed by a 2-layer MLP produces per-function vulnerability scores.
